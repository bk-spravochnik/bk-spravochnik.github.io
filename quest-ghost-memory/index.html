Память всех призраков

С 8 уровня: двенадцать личей у Врат Душ всех городов по порядку, каждому — свой предмет. Награда — «Память всех призраков» с приёмом «Защита Призраков».

Эта статья и весь справочник — в приложении: работает без интернета, с поиском и избранным.

Коротко

С 8 уровня. Обойдите двенадцать личей строго по порядку: у каждого выберите историю призрака, отдайте нужный предмет и дослушайте рассказ. Части памяти копятся до последнего разговора; предметы можно собрать заранее.
